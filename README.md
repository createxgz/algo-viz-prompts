# algo-viz-prompts

> 用提示词驱动算法可视化学习 —— 面向算法学习者的 AI 辅助可视化资源库

本仓库配套《交互式可视化的算法程序设计案例集》教材，收录了所有算法案例对应的：

- **AI 提示词模板**（Prompts）：用于引导 AI 生成算法可视化页面
- **可视化 HTML 源码**：赛博朋克风格的交互式算法演示页面
- **Java 算法源码**：教材中每个案例的完整实现
- **使用指南**：手把手教你用 AI 生成属于自己的算法可视化

## 仓库结构

```
algo-viz-prompts/
├── prompts/              # 提示词模板（按章节分类）
├── visualizations/       # 生成的 HTML 可视化源码
├── java-source/          # 配套 Java 算法源码
├── examples/             # 精选效果展示
└── docs/                 # 使用文档与教程
```

## 快速开始

1. 阅读 [`prompts/PROMPT_GUIDE.md`](prompts/PROMPT_GUIDE.md) 了解提示词写法
2. 浏览 `prompts/` 目录，找到你想学习的算法对应的提示词
3. 将提示词粘贴至任意 AI 对话框（如 Claude、ChatGPT），获得可视化 HTML
4. 打开生成的 HTML 文件，交互式体验算法执行过程
