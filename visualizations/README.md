# 可视化 HTML 源码

本目录收录所有算法案例的交互式可视化演示页面（HTML 格式）。

每个 HTML 文件可直接在浏览器中打开，无需额外依赖。

## 目录说明

| 目录 | 对应章节 |
|------|--------|
| 01_string | 第1章 算法入门（字符串） |
| 02_recursive | 第2章 递归与分治 |
| 03_dp | 第3章 动态规划 |
| 04_greedy | 第4章 贪婪法 |
| 05_backtracking | 第5章 回溯与分支限界 |
| 06_random | 第6章 随机算法 |
| 07_math | 第7章 数学方法 |
| 08_others | 第8章 其他方法 |

> 文件持续更新中。
